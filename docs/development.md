# Desenvolvimento

## Guia de Início Rápido

1. Clone o repositório.
2. Instale dependências: `npm install`
3. Copie `.env.example` para `.env` se necessário.
4. Rode a aplicação: `npm run dev`

## Design System

O projeto obedece um padrão estrito visual:
- Tema: **Dark Premium B2B**
- Sem componentes formatados como *pill* (botões arredondados em excesso). O raio máximo é de 12px.
- Aplicação contida e modular com layout responsivo utilizando componentes de grid embutidos nos Layouts.
